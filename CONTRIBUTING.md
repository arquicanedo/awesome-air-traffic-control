# Contributing

Adding your own project is welcome.

## Adding an entry

Open a pull request that edits `README.md`. One entry per line, in this shape:

```
- [Name](https://example.com) - What it is, in one sentence.
```

- Put it in alphabetical order inside its section.
- Link to the project's own page: a homepage, a store page, or a repository.
- Describe what the software does, not how good it is.
- Prefer the project's own wording over a paraphrase.
- One sentence.

## What gets accepted

Software a controller, a trainee, or someone studying the job would use or learn
from. Simulators, radar clients, navigation and data tooling, training material.

Not accepted: flight simulators and pilot-side add-ons, flight trackers, airline
and airport management games where control is incidental, and anything that is
announced but not yet usable in some form.

## What this list does not do

No ratings, no prices, no review scores, no maintenance-status labels.

If a project has changed enough that its description is now wrong, a pull request
fixing the description is as welcome as a new entry.

## Removals

If you maintain a project listed here and want it removed, open an issue and it
will be removed. No explanation needed.
